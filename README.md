# unknown-casualties-mod-installer
Makes installing mods for "Casualties Unknown" easier and faster.

---

## What it does

- Automatically checks if BepInEx is installed; if not, it installs it for you
- Automatically installs mods—just select the zip file
- If you use the built-in mods, it takes about 30 seconds and just two clicks to finish

Great for people who aren't familiar with computers or don't want to deal with manual installation.

---

## How to use

1. Go to [Releases](https://github.com/drxsgd/unknown-casualties-mod-installer/releases) and download the latest `wzsw_mod_installer.exe`
2. Make sure your game is already installed (Steam version is recommended)
3. Double-click the `.exe` and follow the on-screen instructions

> If you're not using the Steam version, you'll need to manually select your game folder when running the tool.

---

## System requirements

- Windows 10 / 11
- Game must be installed
- If you encounter permission issues, try right-clicking and selecting "Run as administrator". If that doesn't help, check the "Having trouble?" section below.

---

## About the built-in mods

The installer package on Releases comes with some mods pre-included, such as multiplayer mods, QoL (quality of life) mods, and others.

- These mods are sourced from the internet and belong to their respective authors
- This installer is only a tool to help you install mods—it does not modify the mods themselves
- If you are a mod author and feel that your work is included inappropriately, please contact me and I will address it

## A note for non-Chinese users

The installer interface and all built‑in mods are currently in Chinese. If you don't understand Chinese, here's a quick guide to get through the installation:

1. Run the program.
2. Click "确定" (OK) on the first pop‑up prompt.
3. When the program asks you to type `y` or `n`, type `y` and press Enter. You may need to do this 2–3 times depending on your setup.
4. When you see the message `请按回车退出(1/2)` (which means "Press Enter to exit (1/2)"), you can simply close the program window.

All built‑in mods are also in Chinese for now. We plan to add full English localization in a future update. We apologize for any inconvenience.
